# Flag artwork

Bundled 4:3 flag artwork from [flag-icons](https://github.com/lipis/flag-icons), version 7.3.2, under the MIT license in `LICENSE`. Only countries used by the language catalog are included.

The SVG originals are rendered as 128 × 96 PNGs to preserve all flag details across native image renderers. They display at up to 32 × 24 points, with resolution for screens up to 4× density.
